# harmony-app

HarmonyOS 端工程目录。

推荐用 DevEco Studio 6.0.2 Release 或更高版本创建一个新的 Empty Ability / Stage 项目，然后将本目录下设计逐步合入。

第一提交只完成 P0：

1. NotificationSubscriberExtensionAbility
2. `SUBSCRIBE_NOTIFICATION`
3. 系统授权页
4. `NotificationInfo` 调试输出

不要先实现完整 UI 或蓝牙。

详细步骤见 `../docs/HARMONYOS_IMPLEMENTATION.md`。
